# Creator Profiles

## Creating a Profile

1. Connect your Solana wallet
2. Navigate to your Profile page
3. Choose a unique username
4. Add a bio, avatar, and links
5. Save — your public page is live at `/creator/{username}`

## Public Profile

Every creator gets a public page at `https://tipchain.xyz/creator/{username}` that includes:

- Avatar and display name
- Bio and social links
- Tip card (send SOL/USDC)
- Recent tips feed
- Supporter leaderboard

## Verification

Verified creators get a badge on their profile. Verification is managed by platform admins.
