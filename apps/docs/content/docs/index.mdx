# Welcome to TipChain

**TipChain is the open-source infrastructure for creator monetization on Solana.**

Every creator should own their audience, receive direct support without intermediaries, and be able to self-host or extend the platform.

## Quick Links

- [Installation Guide](/docs/installation) — Get started with TipChain
- [Self-Hosting](/docs/self-hosting) — Deploy on your own infrastructure
- [API Reference](/docs/api-reference) — REST and GraphQL APIs
- [SDK Documentation](/docs/sdk) — JavaScript/TypeScript SDK

## Key Features

- **Creator Profiles** — Wallet-connected profiles with custom usernames
- **Direct Tipping** — SOL, USDC, and SPL token support
- **Dashboard** — Analytics, earnings, supporter tracking
- **Memberships** — Recurring subscription tiers
- **NFT Badges** — On-chain supporter rewards
- **Plugin System** — Extend without modifying core code
