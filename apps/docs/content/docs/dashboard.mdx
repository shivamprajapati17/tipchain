# Dashboard

## Overview

The dashboard gives creators real-time visibility into their earnings, supporters, and activity.

## Metrics

- **Wallet Balance** — Current SOL balance
- **Total Earnings** — Lifetime tips received
- **Supporters** — Unique wallets that have tipped
- **Transactions** — Total tip count
- **Average Tip** — Mean tip amount

## Supporters List

An intelligent, auto-prioritized list of your top supporters ranked by total tipped amount.

## Live Status

Real-time status indicators for network, wallet connection, and recent activity with periodic notification pop-ups.

## Quick Actions

Floating action toolbar for quick access to:

- Create/Edit Profile
- View Public Page
- Leaderboard
- Refresh Data
